Genomics Cohorts Knowledge Ontology (GECKO) is an ontology to represent genomics cohort attributes. The GECKO was created in the [CINECA project]( https://www.cineca-project.eu), and standardises attributes commonly used for genomics cohort description as well as individual-level data items. A series of tools is being developed to enable automated generation of harmonised data files based on a JSON schema mapping file.
